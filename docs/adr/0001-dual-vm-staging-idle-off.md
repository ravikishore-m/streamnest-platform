# ADR 0001 — Dual k3s VMs with staging idle-off

## Status

**Superseded** by ADR 0006 (single environment).

## Context

Originally considered separate staging and production k3s VMs with staging powered off when idle, due to limited host RAM.

## Decision (historical)

Dual VMs, staging idle-off. **No longer in force.**

## Superseded by

ADR 0006 — single `streamnest` cluster.
